# Ingeniería de Software II

**Repositorio:** [262is2/demo-is2](https://github.com/262is2/demo-is2)

## Implementación vigente

Por ahora **S1-S2** están publicadas; **S3-S16** se muestran abajo únicamente como referencia de los temas del sílabo vigente (2026-2).

## Producto del curso

**Informe de auditoría del proyecto integrador (o informe de desarrollo de software) basado en CMMI y SCAMPI, fundamentado progresivamente en la NTP ISO/IEC 12207, la ISO/IEC 29110 y la ISO/IEC 25010.**

Al finalizar el curso, el estudiante audita (o desarrolla) un proyecto de software: lo formula mediante un Project Charter fundamentado en la NTP ISO/IEC 12207 y la ISO/IEC 29110 (U1), evalúa su calidad interna y externa con la ISO/IEC 25010 (U2), y sustenta el informe final auditando ambos resultados con el modelo de madurez CMMI y el método SCAMPI (U3).

## Unidad 1: Calidad en los Procesos de Desarrollo de Software con NTP ISO/IEC 12207 e ISO/IEC 29110

**Producto:** Project Charter del proyecto integrador (auditoría o desarrollo de software) fundamentado en la NTP ISO/IEC 12207 y la ISO/IEC 29110.

| Sesión | Tema | Producto de sesión |
|---|---|---|
| [S1](sesiones/S01_NTP_ISO_IEC_12207.md) | NTP ISO/IEC 12207: modelamiento de procesos de ingeniería del ciclo de vida del software. | Mapa de procesos NTP ISO/IEC 12207 priorizados, sistema/proyecto elegido y equipo conformado. |
| [S2](sesiones/S02_Metricas_Proceso_Instrumentos_Aseguramiento.md) | NTP ISO/IEC 12207: métricas de proceso e instrumentos de aseguramiento de la calidad. | Métricas de proceso e instrumentos de aseguramiento (revisiones, inspecciones, checklist). |
| S3 | ISO/IEC 29110: Gestión del proyecto. | Formulación del Project Charter (gestión de proyecto). |
| S4 | ISO/IEC 29110: Ingeniería en el desarrollo del software. | Project Charter del proyecto del semestre. |
| S5 | Evaluación de la Unidad I. | Examen teórico y exposición del Project Charter. |

## Unidad 2: Calidad del Software con ISO/IEC 25010

**Producto:** Avance del proyecto integrador con evaluación de calidad de software según la ISO/IEC 25010.

| Sesión | Tema | Producto de sesión |
|---|---|---|
| S6 | ISO/IEC 25010: Modelo de calidad del software - características internas y externas. | Modelo y priorización de atributos de calidad. |
| S7 | ISO/IEC 25010: Métricas de calidad de código fuente y su relación con code smells. | Niveles y métricas de calidad, code smells identificados. |
| S8 | ISO/IEC 25010: Criterios de valoración del software y refactorización como práctica de mantenibilidad. | Formatos de evaluación y refactorización priorizada por deuda técnica. |
| S9 | ISO/IEC 25010: Evaluación de software y documentación de resultados. | Resultados de evaluación de calidad documentados. |
| S10 | Evaluación de la Unidad II. | Examen teórico y control de avance del proyecto integrador. |
